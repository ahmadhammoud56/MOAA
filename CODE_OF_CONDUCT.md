# Code of Conduct

MOAA follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- Be respectful and constructive.
- Assume good faith.
- Critique ideas, not people.
- Harassment, discrimination and personal attacks are not tolerated anywhere in this project: issues, pull requests, Discussions, or any channel where MOAA is discussed.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@ahmadhammoud56](https://github.com/ahmadhammoud56). You can use GitHub's private reporting under **Security → Report a vulnerability** on this repository, which reaches only the maintainer. Reports are handled confidentially. The maintainer may remove, edit or reject contributions, and may temporarily or permanently ban anyone who violates this code, as described in the Contributor Covenant's enforcement guidelines.
